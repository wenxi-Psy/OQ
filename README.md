# OQ-45.2 在线填写与结果呈现

心理咨询效果问卷（Outcome Questionnaire, OQ-45.2）中文版的网页版填写与计分工具。
纯静态页面，无后端、无构建步骤、无第三方依赖，可直接部署到 GitHub Pages。

**量表版本**：秦佑凤、胡姝婧（2008）中文译本，全 45 题。

---

## 开启 GitHub Pages

代码推送后，需要在仓库里手动开一次（只需一次）：

1. 打开仓库 **Settings → Pages**
2. **Source** 选 `Deploy from a branch`
3. **Branch** 选本分支（或合并到 `main` 后选 `main`），目录选 `/ (root)`
4. 保存，等约一分钟，页面会出现在 `https://<用户名>.github.io/<仓库名>/`

## 实现要点

### 计分

- 五点计分 0–4，分数越高困扰越重。
- **9 道反向题**（1, 12, 13, 20, 21, 24, 31, 37, 43）在 `score.js` 中**只反转一次**。
  存储和导出的逐题分数一律是**作答者勾选的原始值**，CSV 表头已注明"原始未反向"，避免录入时二次反转。
- 三个维度：症状困扰 SD（25 题，0–100）、人际关系 IR（11 题，0–44）、社会角色 SR（9 题，0–36）；
  总分 0–180。

### 第 37 题的「不适用」

第 37 题「我觉得我的爱情关系充实而美好」是**反向计分**。没有恋爱关系的人若勾"不是"，
反转后会变成 4 分（最高困扰），凭空多出 4 分。

页面为该题单独提供了 **「不适用」** 选项，选中后按 0 分困扰计（等价于勾"几乎总是"再反转），
并在题目下方给出提示文字。第 7、17、11、26、32 题为正向计分，"不适用"选"不是"即为 0 分，
页面同样给了小字提示。

### 漏答处理

| 情况 | 处理 |
|---|---|
| 漏答 1–4 题 | 用该题所属**分量表**其余题目的均值（四舍五入取整）填补，结果页明确列出哪几题是估算值 |
| 漏答 ≥ 5 题 | 拒绝出分，提示补答（对应"完成 ≥ 41 题"的门槛） |

### 常模

| 指标 | 数值 | 出处 |
|---|---|---|
| 总分划界分 | **62** | 李钰静 (2010) 中国常模 |
| 总分可信变化指数 RCI | **17** | 李钰静 (2010) 中国常模 |
| 严重度分层 | < 64 低｜64–82 中度｜83–105 中高｜> 105 高 | 美国常模 |
| 分量表划界分 | SD 37｜IR 16｜SR 13 | 美国常模 |

两点在页面上有显式标注：

1. **62 的划界分与 64 起点的严重度分层出处不同**，页面分开呈现，不混用。
2. **62/17 建立在李钰静译本上**，本页面用的是秦佑凤、胡姝婧译本。两译本条目内容高度一致、
   维度归属完全相同，沿用属合理外推，但记录时应注明。中国的分量表划界分与 RCI 未见公开发表，
   页面上的分量表参考线取自美国常模。

分量表分在页面上明确标注为**定性线索**，不作疗效指标——中文版分量表 α 低至 0.57
（秦佑凤、胡姝婧, 2008），不足以支撑单独下结论。

### 变化判定（Jacobson-Truax）

Δ = 基线分 − 当前分（正值表示好转），用中国常模 RCI = 17、划界分 = 62：

| 判定 | 条件 |
|---|---|
| 恢复 | Δ ≥ 17 且 当前分 < 62 |
| 改善 | Δ ≥ 17 但 当前分 ≥ 62 |
| 无变化 | \|Δ\| < 17 |
| 恶化 | Δ ≤ −17 |

页面默认与**上一次**记录比较；若存在被标记为"基线"的记录且不是上一次，会额外给出与基线的比较。

### 关键题跟进

第 **8** 题（自杀意念）**只要不为 0** 即列出；第 **11、26、32、44** 题达到"有时"（≥2）时列出。

第 8 题不为 0 时，结果页顶部会出现一段措辞克制的提示，并附 24 小时心理援助热线
（全国 12356、希望 24 热线 400-161-9995、北京心理危机干预热线 010-82951332）。

## 隐私

**作答数据不会离开浏览器**，页面不发起任何网络请求，也没有任何统计或追踪代码。

每次结果会自动保存到 `localStorage`（键名 `oq45_records_v1`），用于生成变化趋势。
说明页和结果页都提供「清除本机记录」按钮，说明页显示当前已保存的记录数。
共用设备的使用场景在页面上有明确提示。

浏览器禁用本地存储（如无痕模式）时会静默降级：仍可正常填写与出分，只是无法保存和对比。

## 移动端

- 移动优先布局，断点 640px；五点选项在 320px 窄屏下仍保持一行五列，标签自动折行。
- 所有可点按元素热区 ≥ 44px。
- 输入框字号 16px，避免 iOS Safari 聚焦时自动放大页面。
- 适配刘海屏安全区（`env(safe-area-inset-*)`）；进度条粘顶。
- 支持深色模式（跟随系统）、`prefers-reduced-motion`、打印/存 PDF 样式。
- 顺序作答时自动滚动到下一题；回头修改答案时不打断。

| 格式 | 用途 |
|---|---|
| 复制为文字 | 直接贴进个案记录 |
| CSV | 进 Excel / SPSS，含逐题原始分（未反向） |
| JSON | 含原始值、反向计分后的值、维度分、关键题、常模出处 |
| 打印 / 存 PDF | 带到会谈中 |

## 使用限制

本工具是**效果监测工具，不是诊断工具**。分数高低不等于任何诊断，结果需由受过训练的
临床工作者解读。页面上对此有明确说明。

OQ-45.2 是受版权保护的量表，请在已获授权的前提下使用。
